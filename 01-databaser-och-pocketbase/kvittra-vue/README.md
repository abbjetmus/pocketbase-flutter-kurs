# kvittra-vue

Ett litet Vue 3-projekt som pratar med din Kvittra-PocketBase. Det används i
[kapitel 7 – Hämta och lägga till data med Vue](../07-hamta-och-lagga-till-data-med-vue.md).

## Starta

PocketBase måste vara igång på <http://127.0.0.1:8090>. Öppna sedan en terminal
i den här mappen och skriv:

```
npm install
npm run dev
```

Öppna <http://localhost:5173> i webbläsaren.

All kod du skriver hamnar i `src/App.vue`.
